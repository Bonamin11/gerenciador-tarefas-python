# Gerenciador de Tarefas em Python

Projeto de linha de comando desenvolvido em Python para gerenciamento de tarefas.

## Funcionalidades

- Adicionar tarefas
- Listar tarefas
- Editar tarefas
- Remover tarefas
- Marcar tarefas como concluídas
- Visualizar tarefas vencidas
- Estatísticas das tarefas

## Tecnologias utilizadas

- Python
- JSON

## Estrutura do projeto

main.py -> Interface do programa (menu)

tarefas.py -> Lógica das tarefas

utils.py -> Funções auxiliares

tarefas.json -> Armazenamento das tarefas

## Como executar o projeto

Clone o repositório:

git clone https://github.com/Bonamin11/gerenciador-tarefas-python.git

Entre na pasta do projeto:

cd gerenciador-tarefas-python

Execute o programa:

python main.py
